## Project Overview

Cyber-Smart is a browser-based educational game built in response to the 503IT client brief. The game teaches essential cyber security concepts — such as phishing awareness, password hygiene, and safe browsing — to young users aged 8–16 through interactive quiz challenges and timed gameplay scenarios.

The core idea is simple: learning cyber security should feel like playing a game, not sitting through a lecture. Players progress through levels by answering questions correctly and reacting to simulated threats, earning points and unlocking harder scenarios as they go.

---

## The Problem We Are Solving

Young people are increasingly exposed to digital threats — phishing emails, weak passwords, malware — yet formal cyber security education rarely reaches them in an engaging way. Traditional teaching methods result in low retention and disengagement, especially for younger audiences.

Our game addresses this by embedding educational content directly into gameplay, making concepts stick through repetition, challenge, and immediate feedback.

## Game Design Summary

The game follows a simple loop:

**Start Menu → Tutorial → Gameplay → Score Screen → Next Level / Retry**

Players win by reaching a target score or completing all questions in a level. They lose when time runs out or too many incorrect answers are given. Difficulty scales across levels, and each wrong answer is followed by a short explanation of the correct answer to reinforce learning.

The design takes inspiration from fast-paced quiz games (Kahoot!, Trivia Crack) to keep engagement high while ensuring educational value is never lost.
